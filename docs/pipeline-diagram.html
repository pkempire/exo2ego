Exo2Ego Pipeline

Third-Person to Egocentric View Synthesis for Robot Learning · CMSC498E · Dinesh Manocha

Core Contribution

  • • Geometric reprojection: exo → ego without diffusion training
  • • Modular pipeline: swap any pretrained component
  • • Mesh-based hand/object rendering for high-fidelity ego view
  • • Single-view exo input (no multi-camera calibration)

Model Selection Rationale

  • • Depth Anything V2: best zero-shot metric depth, Colab-friendly
  • • FollowMyHold: already solves hand-object pose (don't reinvent)
  • • ProPainter: flow-guided inpainting outperforms diffusion on small VRAM
  • • Wan2.2: bonus video interpolation for demo reel only

Evaluation Plan

  • • Collect paired exo+ego data (GoPro + tripod iPhone)
  • • PSNR / SSIM / LPIPS vs ground truth ego frames
  • • Hand position error (Euclidean, 3D)
  • • Ablation: isolate contribution of each stage
